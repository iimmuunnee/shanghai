# 상하이 3박4일 (2026.9.13–16) — 배포 방법

GitHub Pages에 올려서 링크 하나로 어디서든 보는 방법입니다. **10분, 무료, 카드 등록 없음.**

---

## 1. GitHub 가입 (계정 있으면 건너뛰기)

[github.com](https://github.com) → Sign up → 이메일·비밀번호·아이디 입력.
**여기서 정한 아이디가 나중에 주소가 됩니다.** (예: 아이디가 `hwihoon`이면 → `hwihoon.github.io`)

## 2. 저장소(repository) 만들기

1. 오른쪽 위 **+** → **New repository**
2. **Repository name** 칸에 `shanghai` 입력 (다른 이름으로 하면 주소도 그 이름이 됩니다)
3. **Public** 선택 ← ⚠️ 무료 계정은 Public이어야 페이지가 켜집니다
4. 아래 **Create repository** 클릭

## 3. 파일 올리기

1. 만들어진 화면에서 **uploading an existing file** 링크 클릭
   (안 보이면 **Add file** → **Upload files**)
2. 압축을 푼 폴더 안의 **파일들을 전부 선택해서** 드래그해 넣기
   — 폴더째로 말고, 안에 있는 파일들을 전부입니다
3. 맨 아래 **Commit changes** 클릭

올려야 할 파일:

```
index.html              ← 본체
manifest.webmanifest    ← 홈화면 앱 설정
sw.js                   ← 오프라인 캐시
icon-192.png
icon-512.png
apple-touch-icon.png
robots.txt              ← 검색엔진 차단
.nojekyll
```

> `.nojekyll` 이 안 보이면: 맥은 `⌘ + Shift + .`, 윈도우 탐색기는 보기 → 숨긴 항목 체크

## 4. Pages 켜기

1. 저장소 위쪽 **Settings** 탭
2. 왼쪽 메뉴 **Pages**
3. **Source** → `Deploy from a branch`
4. **Branch** → `main` / `/ (root)` 선택 → **Save**
5. **1~2분 기다렸다가** 새로고침하면 위에 주소가 뜹니다

```
https://<내아이디>.github.io/shanghai/
```

이 주소를 누나들한테 톡으로 보내면 끝입니다.

---

## 나중에 내용 고치고 싶으면

저장소에서 `index.html` 클릭 → 연필(✏️) 아이콘 → 수정 → **Commit changes**.
1분 뒤 자동 반영됩니다. (폰에서 바로 안 바뀌면 아래 '캐시' 참고)

## 폰에서 앱처럼 쓰기

- **아이폰**: Safari로 주소 열기 → 공유 버튼(⬆️) → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열기 → 우측 상단 ⋮ → **홈 화면에 추가**

주소창 없이 전체화면으로 열리고, 아이콘도 동방명주 아이콘으로 나옵니다.

## 오프라인

한 번 열어두면 페이지가 폰에 저장돼서 **비행기 안이나 데이터 안 될 때도** 열립니다.
(단 지도 링크는 인터넷이 있어야 열려요.)

내용을 수정했는데 폰에서 그대로면 캐시 때문입니다 — 페이지를 두 번 새로고침하거나,
홈화면 아이콘을 지웠다 다시 추가하면 됩니다.

---

## ⚠️ 공개 범위에 대해

무료 GitHub Pages는 **주소를 아는 사람이면 누구나 볼 수 있습니다.** 비밀번호는 못 겁니다.

- `robots.txt` + `noindex` 를 넣어놔서 **구글·네이버 검색에는 안 뜹니다**
- 그래도 완전한 비공개는 아니니, 개인정보(숙소 예약번호, 항공권, 연락처 등)는 적지 마세요
- 지금 들어있는 건 맛집·관광지 정보뿐이라 문제없습니다

정말 비공개가 필요하면 GitHub Pro(유료)의 비공개 Pages를 써야 합니다.

## 참고

- `index.html` 파일 하나만 따로 열어도 작동합니다 (앱 아이콘·오프라인 기능만 빠짐)
- 체크리스트는 **폰마다 따로 저장**됩니다. 서로 공유되지 않아요
