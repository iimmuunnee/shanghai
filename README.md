### 1\. 9/14(월)은 예원 정원 휴원

매주 월요일 쉽니다. 예원상가·성황묘는 정상 영업하지만 **정원은 못 들어가요.**

### 2\. 9/13\~16이 하필 태풍 상륙일과 겹칩니다

* 2024년 태풍 **버빙카** — 9월 16일 상하이 상륙 (1949년 이후 최강)
* 2022년 태풍 **무이파** — 9월 14일경 상륙
* 2026년 8월 초 태풍 **돌핀** — 상하이 양대 공항 **943편 결항**

항공·숙소는 **변경/취소 가능 조건**으로, 여행자보험은 **항공 지연·결항 보상 포함**으로 드는 걸 권합니다.
